# Form 1 Maths app: priority checks for a teacher (P1)

Prepared 2026-10-06. These are the open **P1** items: places where a wrong fact or a wrong method would
mislead a pupil who is learning from the app on his own. Please tick ☐ when the item is correct, or write
the correction in the "Correction" column (or on the back of the page) with the item ID.

**How to see the lessons:** open **https://psalmspreps.vercel.app** on a phone. The first visit asks 13
Primary-school questions; you can press "I don't know" for each to reach the lesson menu quickly.
In a lesson: idea cards → worked example → practice. To see the explanation for a mistake, give a wrong
answer; to see the full working, give a wrong answer twice. Every number is generated, so you will see
different numbers each time.

The full text of every lesson (all cards, questions, explanations and working) is in
`content/maths/REVIEW.md`; every question whose answer was written by hand is in `content/maths/AUTHORED.md`.
Item IDs (TR-…) match `docs/teacher-review.md`.

| ☐ | 1 | TR-B01 | **Lesson 1 summary.** Long ago people counted with fingers, stones and sticks (one stone per goat that went out to graze, one taken out per goat that came back); later, tally marks grouped in fives. The Egyptians drew pictures (a lotus flower for one thousand). The Babylonians counted in groups of sixty, "that is why an hour has 60 minutes". The Romans used letters (I, V, X). Our digits 0 to 9 are Hindu-Arabic numerals: they came from India and Arab traders and scholars carried them to other lands. India gave us zero as a number. | |
| ☐ | 1, 2 | TR-B02 | **Egyptian numerals and zero.** Wording used: "Egyptian numerals had no place value, so they did not need a zero digit to hold empty places." | |
| ☐ | 1 | TR-B03 | **The 60-minute hour comes from the Babylonian base-60 (sexagesimal) system.** Is this acceptable as taught at Form 1? | |
| ☐ | 2 | TR-B04 | **Lesson 2 summary.** Egyptian symbols: stroke = 1, heel bone = 10, coil of rope = 100, lotus flower = 1000; add the values of all the pictures (3 lotus flowers and 2 heel bones = 3020). Roman letters: I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000. Equal or smaller letter after: add (VI = 6, XX = 20). Smaller before bigger: subtract (IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900). Never the same letter more than three times in a row (IV, not IIII). 2026 = MMXXVI. | |
| ☐ | 2 | TR-A08 | **Roman numerals accepted by the app:** only the standard form (IV, not IIII); largest number 3999; the six subtractive pairs IV, IX, XL, XC, CD, CM and no others (so 99 = XCIX, not IC). | |
| ☐ | 3 | TR-C29 | **Lesson 3 hints** (shown after "I don't know"), with a sample question each: | |
| | | | • "What is the value of the digit 2 in 971 235?" → *Find the place of the digit 2: count units, tens, hundreds… from the right. Then multiply 2 by the value of that place.* | |
| | | | • "Which digit is in the ten thousands place in 423 313?" → *Start at the right-hand digit (the units) and move left one place at a time until you reach the ten thousands.* | |
| | | | • "Write as one number: 8000 + 20 + 3" → *Each part has its own place. Write 0 in every place that has no part.* | |
| | | | • "Bih pays with 7 notes of 10 000 FCFA, no notes of 1000 FCFA and 6 coins of 100 FCFA. How much?" → *Work out each kind of money on its own (number × value), then add the three amounts.* | |
| | | | • "Order these prices at Limbe market from the smallest to the largest." → *Compare the thousands digits first. If two are the same, compare the hundreds.* | |
| | | | • "Look at the number 371 899. One statement is wrong. Which one?" → *For each statement, find the place of the digit and work out what it stands for.* | |
| | | | • "Write as one number: 4000 + 3" → *4000 has 4 digits. Keep all of them and change only the units digit.* | |
| ☐ | 5 | TR-A04 | **ℕ contains 0; ℕ\* does not** (ℕ = {0, 1, 2, 3, …}; ℕ\* = {1, 2, 3, …}). Symbols ∈ (is an element of) and ∉ (is not an element of). | |
| ☐ | 6 | TR-A07 | **Ordinal endings:** 1st, 2nd, 3rd, 4th…; numbers ending in 11, 12 or 13 take "th" (11th, 12th, 13th, 111th, 112th), but 21st, 22nd, 23rd, 101st. | |
| ☐ | 6 | TR-B09 | **Cardinal, ordinal, nominal.** Cardinal tells how many ("There are 12 mangoes in the basket"); ordinal tells the position or order ("Enow came 3rd in the race"; "Today is the 17th day"); nominal is only a name or label and counts nothing (a phone number, the number on a taxi, a football shirt number). | |
| ☐ | 8 | TR-C29 | **Lesson 8 hints** (number bases): | |
| | | | • "Which of these cannot be a number in base 3?" → *In base 3, the only digits allowed are 0 to 2.* | |
| | | | • "Convert 122 to base 6." → *Divide 122 by 6 again and again until the quotient is 0. Write each remainder, then read them from the bottom up.* | |
| | | | • "Convert 130₆ to base ten." → *Under the digits of 130, write the place values of base 6, ending with …, 6, 1. Multiply each digit by its place value and add.* | |
| | | | • "Convert 1111000₂ to base 4." → *Go through base ten: first change 1111000₂ to base ten, then divide by 4 again and again.* | |
| | | | • "Enow converted 66 to base 5. One line has a mistake." → *Check each line: quotient × 5 + remainder must give back the number that was divided.* | |
| | | | • "Convert 51₈ to base ten." → *Under the two digits, write the place values 8 and 1. Multiply and add.* | |
| | | | • "Convert 5 to base 5." → *Divide 5 by 5, then divide the quotient by 5. Read the remainders from the bottom up.* | |
| ☐ | 9 | TR-C31 | **Borrowing in subtraction in other bases.** The app explains each borrow in plain steps, with no negative numbers. Simple borrow: "2 is less than 3, so it borrows from the next column. In base 5, borrowing gives 5 more: 2 + 5 = 7. Then 7 − 3 = 4." The column that lent: "This 4 lent 1 to the right: 4 − 1 = 3. Then 3 − 1 = 2." Borrowing across a zero: "This 0 already lent 1 to the right and has nothing left, so it borrows from the next column. In base 4, borrowing gives 4. 4 − 1 (what it lent) = 3. Then 3 − 0 = 3." Note: the in-between counts such as "2 + 5 = 7" are counts in base ten. Is this the method and wording you teach? | |
| ☐ | 11, 12 | TR-B05 | **Points and lines.** Through two different points there is exactly one straight line. Any two points are collinear. Three points need not be collinear. | |
| ☐ | 13 | TR-A13 | **Length units ladder:** km, hm, dam, m, dm, cm, mm; each unit is ten times the next one down. | |
| ☐ | 14 | TR-B06 | **Midpoint and its converse.** M is the midpoint of [AB] only if M is on [AB] **and** AM = MB. (AM = MB alone is not enough: M could be off the segment.) | |
| ☐ | 15 | TR-B07 | **Perpendicular bisector.** It passes through the midpoint of [AB] at a right angle (not through A). Every point on it is the same distance from A and B, and every point the same distance from A and B is on it. Construction steps, in order: open the compasses to more than half of AB; draw arcs from A above and below; with the same opening, draw arcs from B; join the two crossing points. | |
| ☐ | 16 | TR-A02 | **"Orthogonal" is taught as meaning "perpendicular" for lines in a plane.** Is this the meaning used in your Form 1 course? | |
| ☐ | 16 | TR-B08 | **Lines in a plane.** Through a point not on a line there is exactly one parallel and exactly one perpendicular to that line. Two lines perpendicular to the same line are parallel. A line perpendicular to one of two parallel lines is perpendicular to the other. If (d₁) // (d₂) and (d₂) // (d₃), then (d₁) // (d₃). | |
