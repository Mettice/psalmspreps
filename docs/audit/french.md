# French (Form 1): question-type audit

Audit only, no content written. Source: `data/spine/french.json` (80 rows: 75 teachable, 5 reuse). Generated by `python tools/audit/build_audit.py`; the judgements are in `tools/audit/audit_data.py`.

**Classes** (one per row, by the main kind of practice the row allows):

- **C** computed: code verifies? yes: code computes the answer
- **F** fact table: code verifies? yes: against an authored table
- **A** authored: code verifies? yes: against an authored key
- **X** paper-only: code verifies? no: self-check against a model answer
- **D** deferred: code verifies? no: needs audio or equipment

Question types: `TPL` templated (computed); `TBL` templated from a fact table; `MCQ` authored MCQ; `CLZ` cloze; `ORD` ordering; `MAT` matching; `MAT(sort)` matching (sort into groups); `LBL` labelling; `SPOT` spot the error; `PAP` paper-only.

Assets: `d:` drawn SVG diagram, `m:` drawn SVG map, `g:` drawn by code from the question data (no file; answers stay computed).

## Engine gaps

- **French conjugation library**: present (regular -er, -cer/-ger, -yer, -eler, e→è), imperative, futur proche; authored tables for avoir, être, faire, prendre, devoir, pouvoir, vouloir, vendre, lire, écrire, suivre.
- **French numbers in words** (1–100), with the chosen spelling convention.
- **Agreement helpers**: articles, partitives, possessives, demonstratives, feminine and plural of nouns and adjectives, elision (l', n', cet), country prepositions; from a noun list with genders.
- **Cloze with French normalisation**: apostrophes ’ vs ', and an accent policy (strict for orthographe and copying rows; lenient elsewhere, with a 'watch the accent' note).
- **French UI strings**: feedback, hints, buttons ('Je ne sais pas') in French for French lessons.
- **Reading passage** type, **paper-only flow**, **audio** (deferred), **matching**, **fact tables**.

## Review burden (P1)

Estimate: **~295 P1 items** = 285 from the rows (33 C × 2 + 13 F × 4 + 23 A × 7 + 2 X × 3; deferred rows count 0 for now) + 5 drawn diagrams or maps (labels must be right) + 5 conventions to settle first:

- Numbers in words: traditional hyphens (vingt et un) or the 1990 rules (vingt-et-un); accept both?
- -yer verbs (payer, balayer): accept both je paie and je paye.
- Nationality capitals: noun capitalised (un Camerounais), adjective not (il est camerounais).
- Accents in typed answers: strict or lenient, per question type.
- The h aspiré list used for ce/cet and elision.

Reviewer: a French teacher (FLE / bilingual-system French). Not the same person as for English.

## Risks and notes

- **Language constraint:** French content in French. Every note, card, hint and feedback line needs a French reviewer, so P1 review cannot be shared with other subjects.
- **National anthem (rows 38, 41):** do not ship the lyrics in the app; the pupil learns them from school or a grown-up. Teach the emblems instead.
- **Reading texts must be original** (about 15 short texts).
- **Typing accents on a phone** is slow for a Form 1 pupil: consider an accent bar (é è ê à ç ù) above the keyboard in cloze questions.
