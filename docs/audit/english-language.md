# English language (Form 1): question-type audit

Audit only, no content written. Source: `data/spine/english-language.json` (104 rows: 101 teachable, 3 reuse). Generated by `python tools/audit/build_audit.py`; the judgements are in `tools/audit/audit_data.py`.

**Classes** (one per row, by the main kind of practice the row allows):

- **C** computed: code verifies? yes: code computes the answer
- **F** fact table: code verifies? yes: against an authored table
- **A** authored: code verifies? yes: against an authored key
- **X** paper-only: code verifies? no: self-check against a model answer
- **D** deferred: code verifies? no: needs audio or equipment

Question types: `TPL` templated (computed); `TBL` templated from a fact table; `MCQ` authored MCQ; `CLZ` cloze; `ORD` ordering; `MAT` matching; `MAT(sort)` matching (sort into groups); `LBL` labelling; `SPOT` spot the error; `PAP` paper-only.

Assets: `d:` drawn SVG diagram, `m:` drawn SVG map, `g:` drawn by code from the question data (no file; answers stay computed).

Grammar is the computable part: tenses, plurals, comparatives, question tags, contractions and conditionals follow rules plus exception tables, so code can build and check them from sentence frames. Vocabulary is fact tables. Reading needs original passages (the biggest authoring and P1 load). Writing and speaking cannot be checked by code. Speech work and listening need audio.

### Offline and audio

Minimal-pair audio at speech quality is roughly 60–120 KB per lesson, so about 1–1.5 MB for all of them: most of the 2 MB budget. Options: a separate optional 'audio pack' downloaded once over Wi-Fi, or a grown-up reads the words aloud from a printed list. Decision for Dion.

**Paper-only: writing and open speaking** (rows marked X). The app shows the task, a model answer and a checklist; the pupil ticks it off; it does not count toward mastery.

## Engine gaps

- **Cloze** (typed word in a gap) with an accepted-answers list and normalisation: case, spaces, curly vs straight apostrophes (don’t / don't).
- **English morphology library**: 3rd person -s, -ing, -ed, plurals, comparatives, contractions, question tags, a/an; plus authored tables of irregular verbs, plurals and a/an exceptions.
- **Sentence frames**: authored sentences with slots (subject, verb, object, polarity) that code inflects, so the answer is computed.
- **Reading passage** item type: one passage, several questions, scroll-friendly at 360px.
- **Generated scenes**: room scene for prepositions (row 27), street grid for directions (row 96), timetable (row 5), form (row 16).
- **Paper-only flow** with model answer and checklist.
- **Audio playback** (deferred; see above).
- **Matching**, **sort into groups**, **fact-table templates**.

## Review burden (P1)

Estimate: **~380 P1 items** = 375 from the rows (19 C × 2 + 22 F × 4 + 27 A × 7 + 20 X × 3; deferred rows count 0 for now) + 2 drawn diagrams or maps (labels must be right) + 3 conventions to settle first:

- British spelling throughout (colour, centre), and whether both learnt/learned, dreamt/dreamed are accepted.
- Question tag for 'I am': aren't I.
- a/an by sound, with an authored exceptions list (an hour, a uniform, a European).

Reviewer: an English teacher. Reading passages also need a check for level (Form 1) and local relevance.

## Risks and notes

- **Reading passages must be original.** Textbook passages are copyrighted; poems must be original or public domain. This is the largest authoring job in any subject (about 12 passages).
- **Comprehension keys are P1:** a wrong key teaches the pupil to read wrongly.
- **Writing quality cannot be checked offline.** Paper-only tasks need a grown-up to look at them now and then; the parent summary should list them.
- **Overlaps:** health and diet (Biology), climate change (Physics, Geography), numbers (Maths).
