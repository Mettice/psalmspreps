# Biology (Form 1): question-type audit

Audit only, no content written. Source: `data/spine/biology.json` (66 rows: 44 teachable, 22 reuse). Generated by `python tools/audit/build_audit.py`; the judgements are in `tools/audit/audit_data.py`.

**Classes** (one per row, by the main kind of practice the row allows):

- **C** computed: code verifies? yes: code computes the answer
- **F** fact table: code verifies? yes: against an authored table
- **A** authored: code verifies? yes: against an authored key
- **X** paper-only: code verifies? no: self-check against a model answer
- **D** deferred: code verifies? no: needs audio or equipment

Question types: `TPL` templated (computed); `TBL` templated from a fact table; `MCQ` authored MCQ; `CLZ` cloze; `ORD` ordering; `MAT` matching; `MAT(sort)` matching (sort into groups); `LBL` labelling; `SPOT` spot the error; `PAP` paper-only.

Assets: `d:` drawn SVG diagram, `m:` drawn SVG map, `g:` drawn by code from the question data (no file; answers stay computed).

### Offline and audio

All rows can work offline. No audio needed. The practicals (rows 6, 8, 14, 18, 52) need a microscope, specimens or materials: the app gives the safety rules, the steps and a self-check, and marks them 'do with a teacher'.

## Engine gaps

- **Matching** and **sort into groups** (used by 17 rows).
- **Labelling**: SVG with numbered pins; the pupil picks a name for each pin (works at 360px, no drag).
- **Fact-table templates**: draw rows from an authored table, with distractors from other rows (an extension of the current `pool` mechanism).
- **Generated food label** (HTML table, values computed) and **food-web graph** helpers (levels, what eats what, effect of removing one species).
- **Paper-only / practical flow**: steps + self-check, not counted toward mastery.
- **Sensitive-content gate** for rows 37–41 (see Risks): a decision, not only code.

## Risks and notes

- **Sensitive topics (rows 37–41: puberty, menstruation, pregnancy, STIs, HIV).** Accuracy is P1 and tone matters. Decide whether these unlock only after a parent has previewed them.
- **Medicinal plants (rows 32–33).** Never give doses or recipes that a child could try. Teach the idea, safety and conservation only.
- **Changing facts (rows 31, 56).** Conservation status and laws change: each fact needs a dated source.
- **Spine oddity, not a fix:** rows 34–36 sit in the 'Role of medicinal plants' chapter but assess 'Understanding soil' (`assesses` field). This is as on the official sheet.
- **Overlaps:** water sources and pollution (Chemistry), food classes (Home Economics). Write once, share.
