# Form 3 Computer Science: points for the subject teacher (TR-S3-n)

Every lesson, Learn screen, card and worked example is **draft**. Open items:

- **TR-S3-1.** Rows 7, 14, 17, 23, 27 and 31 (integration activities) are not written as lessons.
- **TR-S3-2 (rows 1–6).** The AI lessons describe today's narrow AI and machine learning. They stress responsible use: privacy,
  checking AI answers, no plagiarism, and checking a video is real before sharing it. Some AI capabilities change quickly; please check the examples.
- **TR-S3-3 (rows 8–13).** Storage units use 1 KB = 1024 bytes. The processor-cycle lesson uses the program counter and the accumulator.
  Clock-speed questions assume one instruction per cycle per core (a simplification). Mains voltage is given as about 220 V.
- **TR-S3-4 (rows 18–22).** Pseudocode uses ←, IF … THEN … ELSE … ENDIF, FOR … NEXT, WHILE … ENDWHILE and REPEAT … UNTIL.
  Which pseudocode conventions does the school or the GCE board use? Flowchart symbols: oval, parallelogram, rectangle, diamond.
- **TR-S3-5 (rows 24–32).** Software brands are named only as examples (Microsoft Office, LibreOffice, Canva, Zoom). OAPI is named for patents and
  trademarks. The Creative Commons terms are BY, SA, NC, ND and CC0.
