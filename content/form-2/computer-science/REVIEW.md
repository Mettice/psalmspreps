## Lesson 2: Types of processing devices and storage devices

Prerequisites: 1 · Skill: s2-2 (Processing devices and storage devices)

**Note** (draft)

> Processing: the central processing unit (CPU, the processor) is the “brain” of the computer. It has:
> • the control unit, which fetches and decodes instructions and directs the other parts;
> • the arithmetic and logic unit (ALU), which does calculations and comparisons;
> • registers, tiny very fast memories. Its speed is measured in gigahertz (GHz). The graphics processing unit (GPU) handles images. All are fixed on the motherboard.
> Storage:
> • primary (main) memory: RAM (holds programs and data in use; volatile: loses its contents when the power goes off) and ROM (holds start-up instructions; non-volatile, read only);
> • secondary storage keeps data permanently: hard disk drive (HDD), solid-state drive (SSD), USB flash drive, memory card, CD/DVD, cloud storage.

## Lesson 6: The use of appropriate Prompts to generate AI responses

Prerequisites: 4 · Skill: s2-6 (Using good prompts to get AI responses)

**Note** (draft)

> A prompt is the instruction or question you give to an AI system. The quality of the answer depends on the prompt.
> A good prompt is:
> • clear and specific: say exactly what you want (“Explain photosynthesis”, not “photosynthesis”);
> • with context: who it is for and why (“for a Form Two pupil”, “for a class talk”);
> • with a format: how long, what form (“in five sentences”, “as a table”, “three questions with answers”);
> • with limits: what to include or avoid.
> Improve step by step: if the answer is not right, add details and ask again.
> Always check the response: it may contain mistakes. Do not include personal information in prompts.

## Lesson 8: Solving problems 1

Prerequisites: none · Skill: s2-8 (Problem-solving strategies (1))

**Note** (draft)

> Computer scientists solve problems in steps:
> 1. Understand the problem: what is given (the inputs)? What is wanted (the output)?
> 2. Plan a solution: break the problem into smaller parts (decomposition) and write the steps in order (an algorithm).
> 3. Carry out the plan.
> 4. Check (test) the result and improve it.
> An algorithm is a finite list of clear steps, in order, that solves a problem. A recipe or the directions to a friend's house are everyday algorithms.
> Good steps are precise (no guessing), in the right order, and the algorithm stops.

## Lesson 14: Introduction to number systems

Prerequisites: none · Skill: s2-14 (Introduction to number systems)

**Note** (draft)

> A number system (base) uses a fixed set of digits; each place is worth base × the place to its right.
> • Decimal (base 10): digits 0–9; places 1, 10, 100, …
> • Binary (base 2): digits 0 and 1; places 1, 2, 4, 8, 16, … Computers use binary because their circuits have two states (on/off).
> • Octal (base 8): digits 0–7; places 1, 8, 64, …
> • Hexadecimal (base 16): digits 0–9 and A–F (A = 10, B = 11, C = 12, D = 13, E = 14, F = 15); places 1, 16, 256, … Used for colours and memory addresses.
> Write the base as a small number: 1011₂, 17₈, 2F₁₆.
> Value of a numeral: multiply each digit by its place value and add: 1011₂ = 8 + 0 + 2 + 1 = 11.

## Lesson 26: Writing programs in a block programming environment 1

**Note** (draft)

> Block programming (for example Scratch) builds programs by snapping together coloured blocks instead of typing code.
> Key ideas:
> • An event block starts the program (“when green flag clicked”).
> • A sequence is a list of instructions done one after another, in order.

## Lesson 29: Notions on digital Identity

**Note** (draft)

> A digital identity is all the information about a person that exists online: usernames, e-mail addresses, profiles and photos on social media, phone numbers, passwords, posts, likes and comments.

## Lesson 34: Notions on embedded systems and IOT

Prerequisites: 33 · Skill: s2-34 (Embedded systems and the Internet of Things)

**Note** (draft)

> An embedded system is a small computer built into a larger device to do one special job. It has a microcontroller (processor, memory, input and output on one chip), sensors (inputs) and actuators (outputs such as motors, lights, buzzers).
> Examples: washing machines, microwave ovens, digital watches, traffic lights, car engine controls, ATMs, printers, air conditioners.
> The Internet of Things (IoT) is a network of everyday objects with embedded systems that connect to the internet and share data: smart TVs, smart meters (prepaid electricity), smart watches, home security cameras, smart farms, smart city lights.
> How IoT works: a sensor collects data → the microcontroller processes it → the data is sent over the internet → an app or the cloud uses it → an actuator acts.
> Advantages: automation, remote control, saving energy and water. Disadvantages: security and privacy risks, needs internet and power, cost.

## Lesson 36: Notions on Spreadsheet software

Prerequisites: none · Skill: s2-36 (Spreadsheet software)

**Note** (draft)

> A spreadsheet program (Microsoft Excel, LibreOffice Calc, Google Sheets) organises data in a grid of rows and columns, and does calculations.
> • Columns are labelled with letters (A, B, C…), rows with numbers (1, 2, 3…).
> • A cell is where a column and a row meet; its address is the column letter and row number, for example B{3}.
> • A range is a block of cells, for example A{1}:A{5}.
> • A cell can hold text (labels), numbers or a formula.
> • A formula starts with =, for example =A{1}+A{2} or =B{2}*C{2}.
> • Functions are ready-made formulas: =SUM(A{1}:A{5}) adds, =AVERAGE(A{1}:A{5}) finds the mean, =MAX and =MIN find the largest and smallest.
> A file is a workbook; it contains worksheets (sheets).

## Lesson 42: Notions on authentication

Prerequisites: 29 · Skill: s2-42 (Notions on authentication)

**Note** (draft)

> Authentication is checking that a user is really who they claim to be before giving access to a device, an account or data.
> Three kinds of factors:
> • something you know: a password, a PIN, a secret question;
> • something you have: a phone that receives a code (OTP), a bank card, a security key;
> • something you are (biometrics): fingerprint, face, voice, iris.
> Two-factor (multi-factor) authentication uses two different kinds: for example a password and a code sent by SMS — much safer than a password alone.
> Authorisation comes after authentication: it decides what the user is allowed to do.
> Good practice: strong unique passwords, never share codes, lock your screen, log out on shared computers.

## Lesson 43: Notions on backup

Prerequisites: 42 · Skill: s2-43 (Notions on backup)

**Note** (draft)

> A backup is a copy of data kept in another place so that it can be restored if the original is lost.
> Causes of data loss: hardware failure (a dead hard disk), theft or loss of a device, viruses and ransomware, accidental deletion, fire, flood, power cuts.
> Where to back up: an external hard disk or USB flash drive, a memory card, another computer, or the cloud (Google Drive, OneDrive).
> Types: full backup (everything), incremental backup (only what changed since the last backup).
> The 3-2-1 rule: keep 3 copies of important data, on 2 different kinds of storage, with 1 copy in another place (for example in the cloud).
> Back up regularly and test that you can restore the files.
